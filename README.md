# 🐍 Exercícios de Python — Curso em Vídeo

Repositório com todos os **115 exercícios** resolvidos do curso de Python do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor Gustavo Guanabara.

---

## 📚 Sobre o curso

O Curso de Python do Curso em Vídeo é dividido em três módulos e abrange desde os fundamentos da linguagem até estruturas de dados e manipulação de arquivos. Os exercícios cobrem progressivamente os conceitos apresentados em cada aula.

## 🌍 Conteúdo por módulo

### 🟡 Mundo 1 — Fundamentos (Ex001–Ex040)
Introdução ao Python, variáveis, tipos primitivos, entrada e saída de dados, operadores aritméticos, relacionais e lógicos, e primeiras estruturas de controle.
▶️ [Playlist no YouTube](https://www.youtube.com/watch?v=S9uPNppGsGo&list=PLHz_AreHm4dlKP6QQCekuIPky1CiwmdI6)

### 🟠 Mundo 2 — Estruturas de Controle (Ex041–Ex080)
Condicionais (`if`, `elif`, `else`), laços de repetição (`while`, `for`), controle de fluxo (`break`, `continue`), uso de `range()` e funções.
▶️ [Playlist no YouTube](https://www.youtube.com/watch?v=nJkVHusJp6E&list=PLHz_AreHm4dk_nZHmxxf_J0WRAqy5Czye)

### 🔴 Mundo 3 — Estruturas Compostas (Ex081–Ex115)
Listas, tuplas, dicionários, conjuntos, funções com parâmetros e retorno, módulos, tratamento de erros e manipulação de arquivos.
▶️ [Playlist no YouTube](https://www.youtube.com/watch?v=0LB3FSfjvao&list=PLHz_AreHm4dksnH2jVTIVNviIMBVYyFnH)

## 🚀 Como executar

**Pré-requisito:** Python 3.x instalado. [Download aqui](https://www.python.org/downloads/)

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/python-exercicios.git

# Acesse a pasta
cd python-exercicios

# Execute um exercício
python mundo1/ex001.py
```
